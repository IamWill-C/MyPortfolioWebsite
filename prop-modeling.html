Prop Modeling

Pirate Cutlass

This Pirate Cutlass was created for an MMORPG, dubbed Project Darkwater, that I am developing with a small team. The project is currently in pre-production, so this prop is not yet featured in any in-game scenes. However, it serves as a great example of the type of high-quality, game-ready assets I am capable of creating for use in real-time applications.
