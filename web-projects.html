Project Darkwater

Official website for Project Darkwater, a free-to-play pirate MMORPG revival run as a volunteer-driven non-profit. The project began in April 2025 and has grown from five people to 21. I am the creative lead and sole web developer, and I also work on the game as a game designer, 3D artist, and VFX artist. The site is a custom build with a React frontend on Cloudflare and a backend on Railway, styled to match the game's nautical theme. It includes a Captain's Log news section, a gameplay trailer section, an About page with an FAQ, a crew page that lists the team by department, login and sign-up pages, and an application page for open development, creative, and technical roles. The site is live but is not yet the project's main site.
